## 2. 범위

### 2.1 포함 범위 (In Scope)

1. Windows 기반 개발 (개발 PC: Windows)
2. Python + PyQt 기반 Windows 데스크톱 프로그램 또는 Kotlin 기반 Android 앱 (3절에서 결정)
3. 주요 영단어와 뜻 2,000개를 담은 CSV 파일 제공 및 로드
4. 단어 목록 불러오기 / 저장
5. 단어 암기 기능과 단어 시험 기능
6. 설정에 따라 하루 N개 단위로 진도(1일차, 2일차 …) 생성
7. 전날 외운 단어 일부 + 자주 틀린 단어를 학습 세트에 추가
8. 시험은 문제 수를 지정하면 무작위로 출제
9. 출제 비중: 시험 이력이 없거나, 오래되었거나, 자주 틀린 단어를 높게 반영
10. 출제 방향(한→영, 영→한, 혼합) 및 유형(단답형, 4지선다형, OX형) 선택
11. 암기·시험 이력을 파일로 저장하고, 요청 시 보고서 생성

### 2.2 제외 범위 (Out of Scope, 초안)

- 회원가입, 로그인, 여러 사용자 관리
- 서버 저장 및 기기 간 동기화 (로컬 파일 기반)
- 발음 음성 재생 (TTS) — 추후 확장 후보
- 광고, 결제 기능
- 2,000개 이외 단어의 자동 수집 (인터넷 검색, 사전 API 연동)

> 제외 범위는 개발 연습의 완성도를 위해 정한 초안이며, 필요 시 사용자와 협의해 조정합니다.

## 3. 플랫폼 및 기술 방향

요구사항의 "모바일, PC" 중 하나를 먼저 선택해야 합니다. 두 플랫폼을 동시에 만들면 같은 기능을 두 번 구현해야 합니다.

| 구분 | 안 A: PC 프로그램 | 안 B: Android 앱 |
|------|------------------|------------------|
| 언어 / 도구 | Python 3, PyQt (PyQt5 또는 PyQt6) | Kotlin, Android Studio |
| 실행 환경 | Windows 데스크톱 | Android 스마트폰 |
| 장점 | Python 문법이 쉽고, 파일 처리와 데이터 구조 연습에 적합 | 실제 모바일 앱 제작 경험 |
| 단점 | 모바일에서 실행 불가 | 설정(SDK, 에뮬레이터)이 무겁고 학습 곡선이 높음 |
| 권장 | 초보 단계에서 1차 구현 대상으로 권장 | 1차 완성 후 확장 대상으로 권장 |

**결정 상태**: 확정 (2026-10-21, 사용자 승인) — PC(Windows, Python + PyQt)를 1차 구현 대상으로 한다. Android 버전은 M6 확장 후보로 둔다.

**권장 방향 (제안)**: 안 A로 PC 버전을 먼저 완성하고, 단어 데이터(CSV)와 학습 로직을 정리한 뒤 Android 버전으로 확장합니다. CSV 형식을 동일하게 유지하면 두 버전이 같은 데이터를 공유할 수 있습니다.

## 5. 기능별 상세 설명 (초안)

### 5.1 단어 데이터 (REQ-001, REQ-002)

- **단어 CSV 열 구성 (제안)**: `번호, 영단어, 품사, 뜻`
  - 예시: `1, apple, 명사, 사과`
- **인코딩**: UTF-8 (엑셀에서 열 때 한글 깨짐 방지를 위해 UTF-8 with BOM 저장 옵션 검토)
- **단어 수**: 2,000개 (초기 목록). 파일 형식이 맞으면 단어 수에 제한을 두지 않습니다.
- **불러오기**: 파일 선택 → 형식 검사 (열 개수, 빈 칸, 중복 단어) → 목록 표시
- **저장**: 현재 단어장을 같은 형식의 CSV로 저장
- **수용 기준**: 2,000개 파일을 불러와 목록에 모두 표시되고, 저장 후 다시 불러와도 내용이 동일해야 함

### 5.2 단어 암기 (REQ-003, REQ-005)

- 오늘 진도(일차)의 단어를 카드 형태로 표시 (앞면: 영단어, 뒷면: 뜻)
- 다음 / 이전 카드 이동, 뜻 보기 / 숨기기
- **일차 생성 규칙 (초안)**: 전체 단어를 설정값 N개씩 나누어 1일차, 2일차 …로 구성
  - 예: 전체 2,000개, 하루 N=20 → 100일차
  - N의 기본값과 허용 범위는 미정 (예: 10~100)

### 5.3 복습 단어 구성 (REQ-006)

일차 학습 세트는 다음 세 부분으로 구성합니다 (초안).

| 구분 | 설명 | 비율 |
|------|------|------|
| 신규 단어 | 해당 일차에 새로 외울 단어 | N개 중 대부분 |
| 전날 복습 | 전날 외운 단어 중 무작위 일부 | 미정 (예: 전체의 10~30%) |
| 자주 틀린 단어 | 시험에서 오답률이 높은 단어 | 미정 |

- 전날 복습과 오답 단어가 신규 단어와 겹치면 중복 없이 한 번만 포함
- 세부 비율은 설정 화면에서 조정 가능하게 할지 미정

### 5.4 단어 시험 (REQ-004, REQ-007)

**문제 수 지정 후 출제**

- 사용자가 문제 수를 입력하면 단어 풀에서 무작위로 선택
- 단어 풀: 전체 단어 또는 특정 일차 범위 (선택 방식은 미정)

**출제 가중치 (초안)**

| 단어 상태 | 가중치 | 설명 |
|----------|--------|------|
| 시험 이력 없음 | 높음 | 아직 시험 본 적 없는 단어 |
| 마지막 시험 후 오래됨 | 중간~높음 | 마지막 출제 날짜가 오래될수록 높음 |
| 자주 틀림 | 높음 | 누적 오답률이 높을수록 높음 |
| 최근 정답 | 낮음 | 최근에 맞힌 단어 |

- 가중치 수치(예: 1, 2, 3 …)와 계산 방식은 구현 단계의 설계서에서 확정합니다.
- 같은 단어가 한 시험에 두 번 나오지 않도록 합니다.

### 5.5 출제 방향과 유형 (REQ-008, REQ-009)

**출제 방향**

| 방향 | 문제 예시 |
|------|----------|
| 한 → 영 | "사과" → `apple` |
| 영 → 한 | `apple` → "사과" |
| 혼합 | 문제마다 한→영과 영→한을 무작위로 섞음 |

**문제 유형**

| 유형 | 방식 | 채점 |
|------|------|------|
| 단답형 | 직접 입력 | 공백·대소문자 무시 비교 (정답 허용 범위는 미정) |
| 4지선다형 | 보기 4개 중 선택 | 정답 1개 + 무작위 오답 3개 (오답은 같은 세트 또는 전체 단어에서 선택, 미정) |
| OX형 | 제시된 뜻이 맞는지 O/X 선택 | 정답 뜻 또는 무작위 다른 단어의 뜻을 제시 |

- 유형 복수 선택 시 문제마다 무작위로 유형을 정하는 방식으로 제안 (미정)

### 5.6 이력 저장과 보고서 (REQ-010, REQ-011)

**저장 항목 (초안)**

| 항목 | 설명 |
|------|------|
| 날짜·시각 | 암기 또는 시험을 한 시각 |
| 활동 유형 | 암기 / 시험 |
| 단어 | 영단어 |
| 출제 방향·유형 | 시험 조건 |
| 결과 | 정답 여부 |

- **저장 형식 (제안)**: CSV 파일 (엑셀로 열어 확인 가능, 초보 학습에 적합). 설정 값은 JSON 파일로 분리 제안.

**보고서 (초안)**

- 요청 시 생성 (버튼 클릭)
- 기간 선택 (예: 최근 7일, 전체)
- 포함 내용: 학습 일수, 암기 단어 수, 시험 횟수, 평균 정답률, 자주 틀린 단어 목록 Top N
- 출력 형식: 미정 (텍스트 파일, HTML, PDF 중 선택)

## 6. 비기능 요구사항

| 구분 | 요구사항 |
|------|---------|
| 오프라인 동작 | 인터넷 연결 없이 모든 기능 사용 가능 |

| 응답성 | 채점 결과는 답변 직후 표시 |
| 데이터 안전 | 저장 실패 시 기존 파일을 덮어쓰지 않음 (임시 파일 방식 제안) |

## 7. 개발 단계 (마일스톤, 초안)

일정(날짜)은 학습 속도에 맞춰 정하며, 아래는 순서만 정의합니다.

| 단계 | 목표 | 주요 기능 |
|------|------|----------|
| M1 | 데이터 기반 | 단어 CSV 로드, 목록 표시, 저장 |
| M2 | 암기 기능 | 카드 암기, 일차별 진도 생성 |
| M3 | 시험 기능 기본 | 단답형, 4지선다형, OX형, 방향 선택 |
| M4 | 학습 로직 | 이력 저장, 복습 단어 구성, 가중치 기반 출제 |
| M5 | 보고서 | 기간별 학습 보고서 생성 |
| M6 | 확장 (선택) | Android 버전 또는 추가 기능 |

**MVP (최소 기능 제품)**: M1 ~ M3 완료 시점. 이 단계에서 프로그램이 실제로 쓸 수 있는 상태가 됩니다.

## 10. 용어 정의

| 용어 | 정의 |
|------|------|
| 암기 | 카드를 보며 단어와 뜻을 익히는 활동 |
| 시험 | 설정한 조건으로 문제를 풀고 채점받는 활동 |
| 일차 (진도) | 하루에 학습하는 단어 묶음 (예: 1일차 = 1~20번 단어) |
| 복습 단어 | 전날 외운 단어 또는 자주 틀린 단어 |
| 오답률 | 해당 단어를 시험에서 틀린 횟수 ÷ 출제 횟수 |
| 가중치 | 무작위 출제 시 단어가 뽑힐 확률을 높이거나 낮추는 값 |
