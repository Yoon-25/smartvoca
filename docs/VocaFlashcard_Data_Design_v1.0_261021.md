## 2. 단어장 CSV (`voca_2000.csv`)

### 2.1 파일 규격

| 항목 | 규격 |
|------|------|
| 인코딩 | UTF-8 (BOM 없음, 현재 파일 기준) |
| 구분자 | 쉼표 (`,`) |
| 줄바꿈 | CRLF 또는 LF 모두 허용 (읽기), 저장은 Python 기본값 |
| 헤더 | 정확히 `번호,영단어,품사,뜻` (순서 포함) |
| 열 개수 | 4 |
| 뜻 구분 | 뜻이 여러 개면 `/`로 구분 (예: `해/연도`) |
| 쉼표 포함 뜻 | 금지. 저장 시 쉼표가 있으면 큰따옴표로 감싼다 (csv 모듈 기본 동작) |

### 2.2 필드 정의

| 필드 | 타입 | 필수 | 제약 | 예시 |
|------|------|------|------|------|
| 번호 | 정수 | 예 | 1부터 연속 (저장 시 재부여) | 1 |
| 영단어 | 문자열 | 예 | 영문 알파벳만, 공백 없음 (읽기 시 앞뒤 공백 제거) | apple |
| 품사 | 문자열 | 예 | 명사, 동사, 형용사, 부사 중 하나 | 명사 |
| 뜻 | 문자열 | 예 | 1자 이상, `/`로 여러 뜻 구분 | 사과 |

### 2.3 행 검사 규칙 (읽기 시)

| 검사 | 실패 시 처리 (명세서 REQ-001) |
|------|------------------------------|
| 헤더 불일치 | 로드 중단, `WordFileError` |
| 열 개수 ≠ 4 | 해당 행 건너뜀 |
| 영단어 또는 뜻이 빈 칸 | 해당 행 건너뜀 |
| 영단어 중복 (소문자 기준) | 첫 번째만 사용, 나머지 건너뜀 |
| 품사가 허용 목록 밖 | 해당 행 건너뜀 (허용 목록: 명사, 동사, 형용사, 부사) |

건너뛴 행은 `SkipInfo(line_no, reason)`으로 모아 UI에 표시한다.

> **참고**: 현재 `voca_2000.csv`는 위 검사를 모두 통과한다 (검토 결과: 2,000행, 중복 0, 열 개수 오류 0). 품사 허용 목록은 대명사·전치사·접속사가 제외된 뒤 남은 값이다 (ADR-006).

### 2.4 단어 식별 키

- 단어의 식별 키는 **영단어를 소문자로 바꾼 값**이다.
- 이력 파일과 통계는 번호가 아니라 이 키를 사용한다. 번호는 단어장을 재정렬하면 바뀌기 때문이다.

## 3. 메모리 모델 (데이터 클래스)

| 클래스 | 필드 | 설명 |
|--------|------|------|
| `Word` | `key: str`, `english: str`, `pos: str`, `meanings: list[str]`, `index: int` | `index`는 단어장 내 0부터의 순서 (번호 - 1). `meanings`는 `/`로 나눈 토큰 |
| `Settings` | `words_per_day: int`, `prev_review_ratio: float`, `wrong_review_ratio: float`, `default_question_count: int` | 6절 참조 |
| `Progress` | `current_day: int`, `last_study_date: date or None` | 4절 참조 |
| `HistoryRecord` | `timestamp: datetime`, `activity: str`, `session_id: str`, `english: str`, `direction: str`, `question_type: str`, `correct: str` | 5절 참조 |
| `WordStat` | `attempts: int`, `wrong: int`, `last_quiz_date: date or None`, `last_correct: bool or None` | 파일에 저장하지 않고 이력에서 계산 (7절) |
| `StudySet` | `new_words`, `prev_review_words`, `wrong_review_words` | 저장하지 않음. 실행 중 계산 |

## 4. 진도 파일 (`progress.json`)

### 4.1 스키마

```json
{
  "current_day": 1,
  "last_study_date": "2026-10-21"
}
```

| 키 | 타입 | 기본값 | 허용 범위 | 설명 |
|----|------|-------|----------|------|
| `current_day` | 정수 | 1 | 1 ~ 일차 수 | 다음에 학습할 일차 |
| `last_study_date` | 문자열 (YYYY-MM-DD) 또는 null | null | 유효한 날짜 | 마지막으로 일차 학습을 완료한 날짜 |

### 4.2 갱신 규칙

- 한 일차의 암기를 "완료"하면 `current_day`를 완료한 일차 + 1로 올리고, `last_study_date`를 오늘로 바꾼다.
- 이미 지난 일차를 다시 학습해도 `current_day`는 뒤로 가지 않는다 (`max` 규칙).
- 파일이 없거나 JSON이 깨졌으면 기본값으로 시작한다. 깨진 파일은 `progress.json.bak`으로 이름을 바꾼 뒤 기본값을 쓴다.

## 5. 학습 이력 파일 (`study_history.csv`)

### 5.1 스키마

| 열 (순서 고정) | 타입 | 허용 값 | 필수 | 예시 |
|---------------|------|---------|------|------|
| 일시 | 날짜·시각 | `YYYY-MM-DD HH:MM:SS` | 예 | 2026-10-21 14:30:00 |
| 활동 | 문자열 | `암기`, `시험` | 예 | 시험 |
| 세션ID | 문자열 | `S` + `YYYYMMDDHHMMSS`, 암기는 빈칸 | 조건부 | S20261021143000 |
| 영단어 | 문자열 | 단어장의 영단어 (표기 그대로) | 예 | apple |
| 출제방향 | 문자열 | `한→영`, `영→한`, `암기` | 예 | 한→영 |
| 유형 | 문자열 | `단답형`, `4지선다`, `OX`, `암기` | 예 | 4지선다 |
| 정답여부 | 문자열 | `O`, `X`, 암기는 빈칸 | 조건부 | O |

**규칙**
- 헤더는 파일 첫 줄에 한 번만 쓴다. 파일이 없을 때만 헤더를 쓰고 새로 만든다.
- 활동이 `암기`이면 세션ID, 정답여부는 빈칸이다. `시험`이면 둘 다 값이 있어야 한다.
- 한 시험의 모든 문제는 같은 세션ID를 가진다.
- 방향 표기 `→`는 UTF-8 문자이므로 파일을 읽을 때 같은 문자로 비교한다.

### 5.2 행 예시

```csv
일시,활동,세션ID,영단어,출제방향,유형,정답여부
2026-10-21 14:20:00,암기,,apple,암기,암기,
2026-10-21 14:30:00,시험,S20261021143000,apple,한→영,4지선다,O
2026-10-21 14:30:00,시험,S20261021143000,book,영→한,단답형,X
```

### 5.3 읽기 시 검사

| 검사 | 실패 시 처리 |
|------|-------------|
| 열 개수 ≠ 7 | 해당 행 무시 |
| 일시 형식 오류 | 해당 행 무시 |
| 활동이 허용 값 밖 | 해당 행 무시 |
| 시험 행인데 세션ID 또는 정답여부 빈칸 | 해당 행 무시 |

무시한 행 수는 보고서 하단에 표시한다 (명세서 8절 오류 처리 원칙).

## 6. 설정 파일 (`settings.json`)

### 6.1 스키마

```json
{
  "words_per_day": 20,
  "prev_review_ratio": 0.2,
  "wrong_review_ratio": 0.1,
  "default_question_count": 10
}
```

| 키 | 타입 | 기본값 | 허용 범위 | 명세서 근거 |
|----|------|-------|----------|------------|
| `words_per_day` | 정수 | 20 | 10 ~ 100 | 명세서 5절, REQ-005 |
| `prev_review_ratio` | 실수 | 0.2 | 0.0 ~ 0.5 | 명세서 5절, REQ-006 |
| `wrong_review_ratio` | 실수 | 0.1 | 0.0 ~ 0.5 | 명세서 5절, REQ-006 |
| `default_question_count` | 정수 | 10 | 1 ~ 단어 수 | 명세서 5절, REQ-004 |

**검사 규칙**
- 타입이 다르거나 범위를 벗어난 키만 기본값으로 바꾸고, 경고 목록에 키 이름을 담는다.
- `default_question_count`의 상한은 단어 수(2,000)다. 설정 로드 시점에는 단어장 크기를 알 수 없으므로 상한 검사는 시험 시작 시 한다.
- 실수 값은 소수 둘째 자리까지 저장한다 (예: 0.2).

## 7. 통계 (이력에서 계산, 파일 없음)

단어별 통계는 `study_history.csv`의 **시험 행**에서 매번 계산한다. 별도 통계 파일을 두지 않는 이유는 이력이 단일 원본이어야 데이터가 어긋나지 않기 때문이다 (ADR-002와 같은 근거).

| 통계 | 계산 규칙 |
|------|----------|
| `attempts` | 해당 단어의 시험 행 수 |
| `wrong` | 해당 단어의 시험 행 중 정답여부가 `X`인 수 |
| `오답률` | `wrong / attempts` (attempts가 0이면 계산하지 않음, 가중치 규칙에서 "이력 없음" 처리) |
| `last_quiz_date` | 시험 행 중 가장 최근 일시의 날짜 |
| `last_correct` | 시험 행 중 가장 최근 행의 정답여부가 `O`이면 True |

**성능 기준**: 이력 행 1만 건 이하를 전제로 시작 시 한 번 읽어 메모리에서 집계한다. 1인 학습 기록 규모(연간 수천 행)에서는 충분하다.

## 9. 정합성 규칙 (데이터 간 관계)

| 관계 | 규칙 |
|------|------|
| 이력 → 단어장 | 이력의 영단어가 단어장에 없으면 통계에서 제외하지 않고 그대로 집계한다. 보고서에는 "단어장에 없는 단어" 수를 표시한다. |
| 진도 → 설정 | `progress.current_day`가 일차 수보다 크면 마지막 일차로 제한해 표시한다. |
| 전날 복습 → 설정·단어장 | 전날 신규 단어는 저장하지 않고 `words_per_day`와 단어장 순서로 계산한다 (Process Logic 3.2절). `words_per_day`를 바꾸면 전날 범위도 바뀐다. |
| 단어장 저장 → 번호 | 저장 시 번호를 1부터 다시 매긴다. 이력은 영단어 키를 쓰므로 영향이 없다. |

## 10. 개인정보와 보관

- 이력과 진도는 학습자 개인 기록이다. 저장소를 만들면 `.gitignore`에 `data/study_history.csv`, `data/progress.json`, `data/settings.json`, `data/reports/`를 넣는다 (명세서 6절).
- `voca_2000.csv`는 AI가 생성한 학습 데이터이므로 커밋 대상이다. 단, 외부 출처 문장이나 저작물이 섞이지 않았는지 사용자 검토로 확인한다.
