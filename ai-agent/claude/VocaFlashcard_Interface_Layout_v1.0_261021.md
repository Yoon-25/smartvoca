# 스마트 보카 UI/UX 설계서

**파일 위치**: `ai-agent/claude/VocaFlashcard_Interface_Layout_v1.0_261021.md` (초안, 승인 후 `docs/`로 이동)
**작성일**: 2026-10-21
**버전**: v1.0 (초안)
**설명**: 화면 구성, 위젯 배치, 화면 간 이동, 상태별 표시 내용, 메시지 문구를 정의한다.
**기준 문서**: 명세서 v1.1 (4절 화면 목록), 아키텍처 설계서 v1.0 (4절 `ui/` 구조), 프로세스 설계서 v1.0

> 화면 배치는 ASCII 스케치다. 실제 크기와 여백은 PyQt6 구현 시 조정한다. 이 문서는 위젯의 종류와 동작을 정하는 것이 목적이다.

## 1. 화면 구조

프로그램은 **하나의 메인 창**을 가지며, 가운데 영역에 화면을 바꿔 끼운다 (`QStackedWidget`). 별도 창은 설정 대화상자 하나뿐이다.

```
┌─────────────────────────────────────────────────────────┐
│ 스마트 보카                                    [_][□][X] │
├─────────────────────────────────────────────────────────┤
│ [홈] [단어장] [암기] [시험] [보고서]        [설정 ⚙]       │  ← 상단 메뉴 바
├─────────────────────────────────────────────────────────┤
│                                                         │
│              (현재 화면 영역)                             │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ 상태 표시줄: 단어 2,000개 · 오늘 1일차 · 하루 20개          │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 규칙 |
|------|------|
| 상단 메뉴 | 화면 이동 버튼. 현재 화면 버튼은 눌린 모양으로 표시 |
| 상태 표시줄 | 단어 수, 오늘 일차, 하루 단어 수를 항상 표시 |
| 화면 전환 | 암기나 시험 진행 중에는 메뉴로 나가도 되지만, 진행 중이었다는 경고를 먼저 띄운다 |

## 2. 홈 화면 (`main_window.py`의 기본 화면)

```
┌─────────────────────────────────────────────┐
│  오늘의 학습                                  │
│                                             │
│   3일차 (단어 41 ~ 60)                        │
│   신규 20개 · 전날 복습 4개 · 오답 복습 2개      │
│                                             │
│   [ 암기 시작 ]     [ 시험 보기 ]               │
│                                             │
│   마지막 학습: 2026-10-20                       │
└─────────────────────────────────────────────┘
```

| 위젯 | 내용 | 동작 |
|------|------|------|
| 일차 정보 라벨 | `today_day`, 단어 범위 | 프로세스 설계서 1장 계산 |
| 세트 구성 라벨 | 신규·전날 복습·오답 복습 개수 | 암기 화면 진입 전에 3.3~3.4 계산으로 미리 표시 |
| 암기 시작 버튼 | 암기 화면으로 이동 | 세트 구성 후 암기 화면 표시 |
| 시험 보기 버튼 | 시험 설정 화면으로 이동 | - |
| 마지막 학습 라벨 | `last_study_date` | 없으면 "아직 학습 기록 없음" |

## 3. 단어장 화면 (REQ-001, REQ-002)

```
┌─────────────────────────────────────────────────────────┐
│ [불러오기…]  [저장…]                    검색: [______]    │
├─────────────────────────────────────────────────────────┤
│ 번호 │ 영단어    │ 품사   │ 뜻                          │
│ ─────┼──────────┼────────┼─────────────────────────────  │
│   1  │ apple    │ 명사   │ 사과                          │
│   2  │ book     │ 명사   │ 책                            │
│  ... │ ...      │ ...    │ ...                           │
├─────────────────────────────────────────────────────────┤
│ 건너뛴 행 2개 (세부 보기)                                  │
└─────────────────────────────────────────────────────────┘
```

| 위젯 | 종류 | 동작 |
|------|------|------|
| 불러오기 버튼 | 버튼 | 파일 열기 대화상자 → `load_words` → 표 갱신. 실패 시 메시지 상자 |
| 저장 버튼 | 버튼 | 파일 저장 대화상자 → `save_words`. 기본 파일명 `voca_2000.csv` |
| 검색 입력 | 한 줄 입력 | 영단어 또는 뜻에 포함된 글자로 표를 걸러낸다 (대소문자 무시) |
| 단어 표 | 테이블 (읽기 전용) | 행 선택은 가능, 편집은 불가 (1차 버전) |
| 건너뛴 행 링크 | 텍스트 링크 | 누르면 줄 번호와 사유 목록 대화상자 |

**상태**
- 단어장이 비어 있으면 표 대신 "단어장이 비어 있습니다. 불러오기로 CSV 파일을 선택하세요."를 표시한다.
- 불러온 파일 이름을 창 제목 옆에 표시한다 (예: `단어장 - voca_2000.csv`).

## 4. 암기 화면 (REQ-003)

```
┌─────────────────────────────────────────────┐
│  3일차 암기            카드 5 / 20             │
│                                             │
│   ┌───────────────────────────────────┐     │
│   │                                   │     │
│   │             conclude              │     │  ← 앞면 (영단어)
│   │                                   │     │
│   └───────────────────────────────────┘     │
│                                             │
│   [ 뜻 보기 ]                                 │  ← 뒷면 열림 시: 뜻 표시
│                                             │
│   [ ← 이전 ]               [ 다음 → ]          │
│   구분: 신규 · 전날 복습 · 오답 복습              │
└─────────────────────────────────────────────┘
```

| 위젯 | 동작 |
|------|------|
| 카드 영역 | 앞면: 영단어 (큰 글씨). 뜻 보기 후: 영단어 아래에 뜻 |
| 뜻 보기 버튼 | 뜻 표시, 해당 카드의 암기 이력 1행 기록 (카드당 세션 내 1회) |
| 이전 버튼 | 첫 카드에서는 비활성 |
| 다음 버튼 | 마지막 카드에서는 "완료"로 바뀐다. 누르면 프로세스 설계서 4장의 완료 처리 |
| 진행 표시 | "카드 N / 전체" |
| 구분 표시 | 현재 카드가 신규인지 복습인지 표시 (복습 카드에는 "복습" 배지) |

**단축 키 (선택, 구현 시 추가 가능)**: 스페이스 = 뜻 보기, 좌·우 방향키 = 이전·다음.

**완료 메시지**: "3일차 암기를 마쳤습니다. 다음 학습은 4일차입니다." 확인 후 홈 화면으로 이동.

## 5. 시험 설정 화면 (REQ-004, REQ-008, REQ-009)

```
┌─────────────────────────────────────────────┐
│  시험 설정                                    │
│                                             │
│  문제 수     [ 10 ▲▼ ]                        │
│                                             │
│  출제 방향   (●) 한 → 영                      │
│             ( ) 영 → 한                      │
│             ( ) 혼합                          │
│                                             │
│  문제 유형   [✓] 단답형                        │
│             [✓] 4지선다                       │
│             [ ] OX                           │
│                                             │
│  [ 취소 ]                    [ 시험 시작 ]      │
└─────────────────────────────────────────────┘
```

| 위젯 | 종류 | 기본값 | 규칙 |
|------|------|-------|------|
| 문제 수 | 숫자 입력 (스핀박스) | `default_question_count` | 1 ~ 단어 수 |
| 출제 방향 | 라디오 버튼 3개 | 한→영 | 하나만 선택 |
| 문제 유형 | 체크박스 3개 | 단답형 | 최소 1개. 모두 해제하면 시험 시작 버튼 비활성 |
| 시험 시작 | 버튼 | - | 검사 통과 시 시험 화면으로 이동 |

**검사 메시지**
- 문제 수가 단어 수보다 크면: "단어 수(2,000개)보다 큰 값입니다. 2,000문제로 조정합니다." 후 자동 조정.
- 유형을 모두 해제하면 버튼이 비활성화되고 "문제 유형을 하나 이상 선택하세요."를 표시한다.

## 6. 시험 화면 (REQ-004, REQ-009)

### 6.1 문제 표시 (유형별)

**단답형**
```
┌─────────────────────────────────────────────┐
│  문제 3 / 10                     [한 → 영]     │
│                                             │
│   뜻:  가게                                   │
│                                             │
│   답: [______________]           [ 제출 ]     │
└─────────────────────────────────────────────┘
```

**4지선다형**
```
┌─────────────────────────────────────────────┐
│  문제 4 / 10                     [영 → 한]     │
│                                             │
│   단어:  conclude                             │
│                                             │
│   ( ) 결론짓다   ( ) 가게                       │
│   ( ) 집중하다   ( ) 돕다                      │
│                                             │
│                                  [ 제출 ]     │
└─────────────────────────────────────────────┘
```

**OX형**
```
┌─────────────────────────────────────────────┐
│  문제 5 / 10                     [한 → 영]     │
│                                             │
│   뜻:  가게      ↔      영단어:  bridge        │
│                                             │
│   [ O ]                    [ X ]             │
└─────────────────────────────────────────────┘
```

### 6.2 답 제출 후 (정답 표시)

| 상황 | 표시 |
|------|------|
| 정답 | 초록색 "정답입니다." |
| 오답 | 빨간색 "오답입니다. 정답: …" (정답이 여러 개면 모두 나열, 예: `store, shop`) |

- 제출 후 입력 칸과 보기 버튼은 비활성화된다.
- "다음 문제" 버튼으로 다음 문제로 넘어간다. 마지막 문제에서는 "결과 보기"로 바뀐다.
- 이력은 제출과 동시에 기록되므로 화면에 별도 표시는 없다.

### 6.3 시험 종료 화면

```
┌─────────────────────────────────────────────┐
│  시험 결과                                    │
│                                             │
│   7 / 10 정답  (70%)                          │
│                                             │
│   틀린 단어: book, conclude, bridge            │
│                                             │
│   [ 홈으로 ]                  [ 다시 시험 ]     │
└─────────────────────────────────────────────┘
```

- 틀린 단어 목록은 이 세션에서 틀린 단어만 보여준다.
- "다시 시험"은 같은 설정으로 새 세션을 만든다 (새 세션ID).

## 7. 설정 대화상자 (명세서 5절)

```
┌─────────────────────────────────────────────┐
│  설정                                         │
│                                             │
│  하루 단어 수          [ 20 ▲▼ ]  (10 ~ 100)   │
│  전날 복습 비율        [ 20 ▲▼ ] %  (0 ~ 50)    │
│  오답 복습 비율        [ 10 ▲▼ ] %  (0 ~ 50)    │
│  기본 문제 수          [ 10 ▲▼ ]  (1 ~ 2000)   │
│                                             │
│  [ 기본값 복원 ]         [ 취소 ]   [ 저장 ]     │
└─────────────────────────────────────────────┘
```

| 위젯 | 규칙 |
|------|------|
| 스핀박스 | 허용 범위를 넘으면 입력을 막는다 (`QSpinBox`의 최소·최대) |
| 비율 입력 | 화면에서는 %로 입력받고, 저장 시 0.2처럼 소수로 바꾼다 |
| 기본값 복원 | 네 값을 기본값으로 채운다. 저장은 하지 않는다 |
| 저장 | `save_settings` 호출, 성공 시 대화상자 닫기 |

**변경 적용 시점**
- 하루 단어 수를 바꾸면 일차 번호와 단어 범위가 바뀐다. 저장 전에 "일차 구성이 바뀝니다. 계속할까요?"를 한 번 묻는다.
- 나머지 설정은 저장 즉시 다음 계산부터 적용된다.

## 8. 보고서 화면 (REQ-011)

```
┌─────────────────────────────────────────────┐
│  보고서                                       │
│                                             │
│  기간  ( ) 최근 7일  ( ) 최근 30일  ( ) 전체     │
│                                             │
│  [ 보고서 만들기 ]                              │
│                                             │
│  ┌───────────────────────────────────────┐   │
│  │ (생성된 보고서 텍스트 미리보기)          │   │
│  │ 학습 일수: 5                           │   │
│  │ 암기 단어 수: 100                       │   │
│  │ …                                     │   │
│  └───────────────────────────────────────┘   │
│  저장 위치: data/reports/report_….txt        │
└─────────────────────────────────────────────┘
```

| 위젯 | 동작 |
|------|------|
| 기간 라디오 | 기본값 최근 7일 (D5) |
| 보고서 만들기 | 집계 후 미리보기에 표시하고 파일 저장 |
| 미리보기 | 읽기 전용 텍스트 영역 |
| 저장 위치 | 저장된 파일 경로. 누르면 폴더 열기 (선택 기능) |

**상태**: 이력이 없으면 미리보기 자리에 "이력이 없습니다. 암기나 시험을 한 뒤 다시 시도하세요."를 표시하고 파일을 만들지 않는다.

## 9. 메시지 문구 목록

| 상황 | 문구 |
|------|------|
| 단어 파일 헤더 오류 | "단어 파일의 헤더가 올바르지 않습니다. 필요한 헤더: 번호,영단어,품사,뜻" |
| 건너뛴 행 있음 | "N개 행을 건너뛰었습니다. 자세히 보려면 클릭하세요." |
| 설정 값 범위 오류 | "설정 값 X가 허용 범위를 벗어나 기본값으로 바꿨습니다." |
| 진도 파일 손상 | "진도 파일을 읽을 수 없어 1일차부터 시작합니다. 이전 파일은 progress.json.bak으로 보관했습니다." |
| 저장 실패 | "파일을 저장하지 못했습니다. 기존 파일은 그대로 있습니다. (원인: …)" |
| 문제 수 조정 | "단어 수보다 큰 값이어서 N문제로 조정했습니다." |
| 유형 미선택 | "문제 유형을 하나 이상 선택하세요." |
| 진행 중 화면 이동 | "진행 중인 학습이 있습니다. 나가면 진행 상황이 사라집니다. 나가시겠습니까?" |
| 일차 구성 변경 | "하루 단어 수를 바꾸면 일차 구성이 달라집니다. 계속할까요?" |
| 이력 없음 (보고서) | "이력이 없습니다. 암기나 시험을 한 뒤 다시 시도하세요." |

## 10. 화면 간 이동도

```
            ┌──────────┐
            │   홈     │
            └────┬─────┘
   ┌────────────┼─────────────┬──────────────┐
   ▼            ▼             ▼              ▼
┌────────┐ ┌──────────┐ ┌──────────┐  ┌──────────┐
│ 단어장  │ │  암기     │ │ 시험 설정 │  │  보고서   │
└────────┘ └────┬─────┘ └────┬─────┘  └──────────┘
                │ 완료        │ 시작
                ▼            ▼
              홈          ┌──────────┐
                          │  시험     │
                          └────┬─────┘
                               │ 종료
                               ▼
                             홈 / 다시 시험(시험 설정 값 유지)

  설정 대화상자: 상단 메뉴의 [설정 ⚙]에서 어느 화면에서나 연다.
```

## 11. 접근성·사용성 기준

| 항목 | 기준 |
|------|------|
| 글자 크기 | 영단어 카드 24pt 이상, 본문 12pt 이상 |
| 색 | 정답·오답은 색과 문구를 함께 쓴다 (색맹 대비) |
| 키보드 | 시험 화면에서 Enter로 제출, 4지선다는 1~4 숫자 키로 선택 |
| 한글 입력 | 단답형 입력 칸은 입력 모드 영향을 받지 않도록 영문 입력은 그대로 받는다 |
| 빈 상태 | 데이터가 없는 화면마다 안내 문구를 표시한다 (단어장, 보고서) |
