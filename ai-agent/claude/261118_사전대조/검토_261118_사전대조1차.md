# 단어 뜻 사전 대조 1차 결과 (이슈 #7)

**파일 위치**: `ai-agent/claude/261118_사전대조/검토_261118_사전대조1차.md`
**작성일**: 2026-11-18
**버전**: v1.0 (초안)
**설명**: 단어장 1~1883번의 뜻·품사를 kaikki.org(Wiktionary) 데이터와 자동 대조한 1차 결과와 다음 단계를 정리한다.

---

## 1. 방법

- 원본: `kaikki.org-dictionary-English.jsonl` (3.4GB, CC BY-SA). 스트리밍으로 읽어 단어장 1,883개 단어에 해당하는 항목만 추출 (`script/extract_kaikki_subset.py`). 원본은 저장하지 않음.
- 대조: CSV 뜻 토큰과 사전의 한국어 번역(`lang_code=ko`)을 비교 (`script/compare_meanings.py`).
- 판정 기준
  - 일치: 뜻 토큰과 한국어 번역이 겹침
  - 불일치 의심: 한국어 번역은 있으나 겹치지 않음 (사전 항목 내 다른 의미일 수 있음)
  - 확인 불가: 한국어 번역 없음

## 2. 결과

| 판정 | 개수 | 비율 |
|------|------|------|
| 일치 | 283 | 15.0% |
| 불일치 의심 | 140 | 7.4% |
| 확인 불가 | 1,460 | 77.5% |

- 상세: `대조결과_261118.csv`
- 품사 불일치로 표시된 항목은 없음.

## 3. 해석

- 확인 불가가 대부분이다. Wiktionary의 한국어 번역은 항목이 드물어 사전 부재를 오류로 볼 수 없다.
- 불일치 의심 140개를 샘플로 보니 대부분 사전의 다른 의미(예: book → 예약하다, tooth → 톱니)라 실제 오류는 확인되지 않았다. 다만 "about → 거꾸로"처럼 번역이 엉뚱한 항목도 섞여 있다.
- 따라서 자동 대조로는 정확성을 판정할 수 없다. 단어장 수정은 하지 않았다.

## 4. 다음 단계 (제안)

1. 불일치 의심 140개: 사용자가 보유한 영한사전으로 확인.
2. 확인 불가 1,460개: 사전 파일이 있으면 같은 방식으로 대조. 없으면 표본 검사 후 정확도 추정.
3. 틀린 항목이 확정되면 수정안을 승인받은 뒤 `data/voca_2000.csv`에 반영.

## 5. 미결 사항

- 사용자 보유 사전의 형식(인쇄본, 앱 내보내기 등)에 따라 대조 방식이 달라진다.

## 6. 2차 대조 결과 (불일치 의심 140개)

- 라이선스 확인 가능한 사전: 한국어 위키낱말사전 (ko.wiktionary.org, CC BY-SA 4.0). 공개 MediaWiki API로 표제어 원문을 받았다 (`script/fetch_ko_wiktionary.py`, 원문 `data/ko_wiktionary_raw.json`).
- 자동 비교(`script/verify_with_ko_wiktionary.py`): 확인됨 104 / 불일치 재확인 25 / 확인 불가 10 / 품사 확인 필요 1.
- 사람 판정(`script/finalize_suspicious.py`, 결과 `최종판정_261118.csv`):

| 최종 판정 | 개수 | 의미 |
|-----------|------|------|
| 적합 (사전 일치) | 104 | 위키낱말사전 뜻 풀이와 일치 |
| 적합 (표현 차이) | 21 | 같은 뜻이지만 활용형이나 표현이 다름 (예: 큰 ↔ 크다, 빠른 ↔ 빠르다) |
| 적합 (사전 미확인) | 14 | 위키낱말사전에 해당 뜻이 없어 일반 지식으로 판단 |
| 적합 | 1 | low: 형용사 뜻은 맞음 |
| 틀림 | 0 | - |

- 결론: 불일치 의심 140개에서 뜻이 틀린 항목은 찾지 못했다. 단어장은 바꾸지 않았다.
- 한계: "적합 (사전 미확인)" 14개와 "적합 (표현 차이)" 중 일부는 사전 근거가 없거나 약하다. 필요하면 다른 사전으로 추가 확인한다.
- 확인 불가 1,460개는 아직 대조하지 않았다. 같은 방식으로 위키낱말사전을 조회할 수 있다 (약 1,460회 요청).

## 7. 확인 불가 1,460개 대조 결과

- 한국어 위키낱말사전 표제어 1,460개 조회: 1,458개 원문 확보 (`data/ko_wiktionary_raw_unverified.json`). 요청 과다(429)로 재시도했다.
- 자동 비교(`script/verify_unverified.py`, 뜻 풀이 줄 파싱은 `verify_with_ko_wiktionary.py` 공용):
  - 확인됨 1,055 / 품사 확인 필요 15 / 재확인 필요 357 / 뜻 풀이 없음 33
- 최종 판정(`script/finalize_unverified.py`, 결과 `미확인1460_최종판정_261118.csv`):

| 최종 판정 | 개수 |
|-----------|------|
| 적합 (사전 일치) | 1,055 |
| 적합 (품사 주의) | 15 |
| 적합 (표현 차이) | 357 |
| 적합 (사전 미확인) | 33 |
| 틀림 | 0 |

- 재확인 필요 357개: 자동 비교가 활용형(큰 ↔ 크다)을 못 읽어서 나온 항목이다. 목록을 직접 읽어 확인했고 뜻이 틀린 항목은 찾지 못했다.
- 사전 미확인 33개(neighbor, service, attention 등): 위키낱말사전에서 뜻 풀이를 읽지 못해 일반 지식으로 적합 판정했다.

### 한계

- 사용한 사전은 위키낱말사전 한 곳이다. 다른 라이선스 사전으로 교차 확인하지 않았다.
- 재확인 357개는 자동 비교 후 사람이 읽은 결과다. 전수 검증이 아니다.
- 단어장 데이터는 수정하지 않았다.
