## 4. 아직 결정되지 않은 사항 (다음에 물어볼 내용)

1. **PyQt6 설치 승인 (필수, 구현 시작 전)**
   - 설계서 2절 규칙상 환경 변경이므로 구현 시작 시 승인받아야 함.
   - 질문 예: "`pip install PyQt6`를 실행해도 되나요?"
2. **구현 순서 승인**
   - 제안: 단어 데이터 로드 → 일차 계산 → 암기 화면 → 시험 출제·채점 → 이력 저장 → 보고서
   - 질문 예: "이 순서로 진행해도 될까요?"
3. **접속 부사 제외 여부 (ADR-006 범위)**
   - `however`, `therefore`, `moreover`, `otherwise`, `besides`, `accordingly`, `instead` 등은 제외 목록에 없어 현재 유지됨.
   - 질문 예: "접속 부사도 기능어로 보고 제외할지, 그대로 둘지"
4. **`on`, `about` 처리 방식**
   - 현재는 유지. 나중에 ADR-006에 예외로 명시할지 정해야 함.
5. **1~1883번 사전 대조 여부 (선택)**
   - 현재 검토는 제 지식 기반. 사전으로 재확인이 필요한지 결정 필요.
6. **앞으로의 ADR 후보**
   - 설계서 10절에 추가 ADR 후보는 ADR-007·008로 모두 반영됨. 구현 중 새 결정이 생기면 ADR-009부터 기록.
