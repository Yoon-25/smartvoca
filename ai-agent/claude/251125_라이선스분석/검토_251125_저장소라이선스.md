# 검토 251125: 저장소 라이선스 (이슈 #11)

**작성일**: 2026-11-25
**목적**: 라이선스를 정하기 위한 사실 정리와 선택지. 결정은 사용자가 한다.

## 1. 현재 상태 (사실)

- 저장소: `Yoon-25/smartvoca`, **private**. LICENSE 파일 없음.
- 기본 상태에서는 저작권이 전부 작성자에게 있다. 제3자가 사용할 권리가 주어지지 않은 상태다.
- 저장소에 커밋된 외부 자료 (사전 대조 산출물):
  - `ai-agent/claude/261118_사전대조/data/ko_wiktionary_raw.json`, `ko_wiktionary_raw_unverified.json`: 위키낱말사전 원문 (CC BY-SA 4.0)
  - `ai-agent/claude/261118_사전대조/data/kaikki_subset.json`: kaikki.org(Wiktextract) 추출본. Wiktionary 기반이라 CC BY-SA 조건이 따른다
  - 대조 결과 CSV와 검토 메모에 사전 뜻 풀이 요약이 들어 있다
  - `ai-agent/claude/251125_사전재확인/ko_defs62.json`은 조회 결과 파일이다 (아직 커밋 전)
- 단어장 `data/voca_2000.csv`는 영단어, 품사, 뜻을 담는다. 뜻은 사전 검토를 거쳤지만 원문 복사는 아니다.
- 개인 학습 데이터(`progress.json`, `study_history.csv`, `settings.json`)와 `.bak`, `.draft` 파일은 `.gitignore`로 제외되어 있다.
- ADR-010: 외부 사전 자료는 라이선스가 명확한 개방형 자료만 쓴다. CC BY-SA는 이 조건을 만족하지만 **출처 표시와 같은 조건 적용**이 따른다.

## 2. 선택지

| 안 | 내용 | 장점 | 단점 |
|----|------|------|------|
| A | 비공개 유지, 라이선스 없음 (현재) | 결정 없이 유지. 사전 원문 문제가 밖으로 나가지 않음 | 외부 사용 권리 없음. 공개 전에는 결정 필요 |
| B | 공개 + 코드 MIT, 데이터는 별도 CC BY-SA 4.0 | 코드 재사용이 자유롭다. 사전 파생 데이터는 조건이 명확 | 파일마다 라이선스를 나눠야 한다. 사전 원문 파일을 정리해야 한다 |
| C | 공개 + 저장소 전체 CC BY-SA 4.0 | 한 가지 라이선스로 단순 | 코드까지 같은 조건이 붙는다. 일반적인 소프트웨어 관행과 맞지 않는다 |
| D | 공개 + 코드 Apache-2.0 또는 MIT, 사전 파생 파일 제외 | 사전 문제를 피한다 | 단어 뜻 검토 기록을 공개하지 못한다. 단어장 뜻의 출처가 불투명해진다 |

## 3. 권장 (사용자 결정 전 의견)

1. **지금은 A 유지.** 저장소가 private이므로 긴급하지 않다.
2. **공개를 정하면 B 또는 D.**
   - B를 고르면: 사전 원문 JSON(`ko_wiktionary_raw*.json`, `kaikki_subset.json`)은 CC BY-SA 파일로 따로 표시하고, 출처 표기 문구를 넣는다.
   - D를 고르면: 사전 원문 파일과 뜻 풀이 요약 CSV를 공개 범위에서 뺀다. 검토 결론만 남긴다.
3. 공개 전에 이슈 #12의 확인이 끝나 있어야 단어장 뜻의 근거가 정리된다.

## 4. 사용자가 정해야 할 것

- 공개 여부 (지금 유지 / 공개)
- 공개한다면 선택지: B, C, D 중 하나 (또는 다른 라이선스)
- 사전 원문 파일을 저장소에 계속 둘지, 공개 범위에서 뺄지
