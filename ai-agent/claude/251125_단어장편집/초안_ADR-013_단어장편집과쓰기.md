# ADR-013 초안: 단어장 편집과 파일 쓰기

**상태**: 초안. `docs/` 반영은 사용자 승인 후 진행 (결정 기록 v1.6으로 올림, v1.5는 `docs/old/`로 이동)

## ADR-013 단어장 편집은 메모리 초안에서 하고, 저장할 때 파일에 쓴다

- **배경**: 단어장 편집(추가, 수정, 삭제)과 웹에서의 쓰기 기능이 필요해졌다 (2026-11-25 사용자 요청). 편집 중 실수로 파일이 바뀌거나, 저장 전에 일차 구성이 바뀌는 문제를 막아야 한다. ADR-011은 단어장을 바꿔도 진도와 이력을 유지한다고만 정했다.
- **대안**
  - A. 편집 즉시 파일에 쓰기: 실수가 바로 파일에 남고, 취소할 방법이 없다.
  - B. 메모리 초안에서 편집하고 "저장"으로 파일에 쓰기 (채택)
  - C. 데이터베이스로 옮겨 편집 기록 관리: 저장 형식을 바꾸는 큰 변경이라 ADR-002와 충돌한다.
- **결정**: B안.
  1. 편집은 메모리 초안에서 한다. 파일은 "저장"을 눌러야 바뀐다. 취소하면 파일 내용으로 되돌린다.
  2. 저장할 때 기존 파일을 `<원본>.bak`으로 복사해 둔 뒤 원자적으로 교체한다 (`save_words_with_backup`). 백업은 직전 저장 한 번분만 남는다.
  3. 저장 전 확인이 필요한 경우를 정한다.
     - 단어 순서나 개수가 바뀌면 일차 구성이 달라진다 (키 순서 비교). 진도는 그대로 둔다.
     - 건너뛴 행이 있으면 저장 시 파일에서 사라진다 (백업에는 남는다).
     - 뜻이나 품사만 고친 경우는 확인 없이 저장한다.
  4. 단어장 불러오기는 초안으로만 들어간다. 저장하지 않은 변경이 있으면 버리기를 확인받는다.
  5. 진행 중인 암기·시험이 있으면 편집, 저장, 불러오기, 취소를 모두 막는다 (설정 변경과 같은 기준, ADR-011).
  6. 검증 규칙은 `services/word_editor.py` 한 곳에 둔다. 영단어 필수, 품사는 명사·동사·형용사·부사 중 하나, 뜻 한 개 이상, 영단어 중복 금지(대소문자 무시).
- **결정 근거**
  - 저장 전에는 실수가 파일에 닿지 않는다.
  - 일차 구성이 바뀌는 순간을 한 번 확인받아 사용자가 의도를 알 수 있다.
  - 데스크톱과 웹이 같은 규칙과 같은 파일 형식을 쓴다.
- **제약**
  - 초안은 메모리에만 있다. 웹 서버나 데스크톱 앱을 종료하면 저장하지 않은 변경은 사라진다. 종료 전에 확인 창을 띄운다 (데스크톱). 웹은 서버 종료 시 경고가 없다.
  - 데스크톱과 웹이 같은 파일을 동시에 편집하면 마지막에 저장한 쪽이 이긴다. ADR-012의 "동시 실행 금지"를 따른다.
  - 웹의 "CSV 불러오기"는 초안으로만 읽는다. 저장 대상은 항상 `data/voca_2000.csv`다. 데스크톱은 불러온 파일 자체에 저장한다 (기존 동작 유지).
- **관련 요구사항**: REQ-001, REQ-002, ADR-011, ADR-012
