## 2. 일차 범위 계산

일차 `d`(1부터 시작)의 신규 단어 범위는 단어장 인덱스(0부터)로 표현한다.

```
start = (d - 1) * N
end   = min(d * N, 단어 수)          # 끝 번호는 제외
range = words[start:end]
```

- 마지막 일차는 남은 단어만 포함한다.
- 일차 번호 → 단어: `day_of(word) = word.index // N + 1`

## 3. 학습 세트 구성 (REQ-006)

암기 화면을 열 때 한 번 계산한다. 결과는 저장하지 않는다 (데이터 설계서 9절).

### 3.1 입력

- `d`: 학습 일차
- `N`: `words_per_day`
- `r_prev`: `prev_review_ratio`, `r_wrong`: `wrong_review_ratio`
- `history`: 이력 전체 (통계 집계는 7장)

### 3.2 전날 복습 단어 (`prev_review_words`)

| 조건 | 결과 |
|------|------|
| `d = 1` | 빈 목록 |
| `d > 1` | 후보 = 직전 일차(`d-1`) 범위 단어 중 **암기 이력이 있는 단어**. 후보에서 무작위 `k_prev = round_half_up(N × r_prev)`개 (후보가 적으면 있는 만큼) |
| 직전 일차에 암기 이력이 하나도 없음 | 빈 목록 (명세서 REQ-006의 "전날 학습 기록이 없으면" 규칙) |

- "전날"은 **직전 일차**를 뜻한다. 날짜가 아니다. 매일 한 일차씩 학습하면 둘은 같다. 여러 날 쉬었다가 다시 시작해도 직전 일차를 복습한다.
- 직전 일차의 범위는 데이터 설계서 9절에 따라 현재 `N`으로 계산한다.
- 암기 이력이 있는 단어만 후보로 삼는 이유는, 외운 적 없는 단어를 복습으로 넣지 않기 위해서다.

### 3.3 오답 복습 단어 (`wrong_review_words`)

1. 후보: 시험 이력이 있고 `wrong ≥ 1`인 단어 전체.
2. 정렬: 오답률 내림차순, 같으면 `wrong` 내림차순, 그래도 같으면 영단어 오름차순.
3. 상위 `K = min(후보 수, 3 × k_wrong)` 단어를 잘라낸다. (상위에서만 뽑아 "자주 틀린 단어"를 유지)
4. 상위 K에서 무작위 `k_wrong = round_half_up(N × r_wrong)`개를 뽑는다.
5. 후보가 `k_wrong`보다 적으면 있는 만큼만 쓴다.

### 3.4 신규 단어 (`new_words`)

1. 일차 범위(2장)에서 복습 단어와 겹치는 단어를 제외한 목록을 만든다.
2. 앞에서부터 `N - |prev_review| - |wrong_review|`개를 취한다.
3. 일차 범위가 모자라면(마지막 일차) 범위 바깥의 단어는 쓰지 않는다. 세트 크기가 N보다 작아질 수 있다.

> **중복 방지**: 같은 단어가 두 복습 목록에 동시에 들어가면 `wrong_review`에서 먼저 제외하고, 그래도 빈자리는 3.4의 신규 단어로 채운다. 최종 세트에 같은 단어는 한 번만 있다.

### 3.5 출력 순서

암기 카드 순서는 `신규 → 전날 복습 → 오답 복습`이다. 신규 단어를 먼저 보여준다. 사용자가 요청하면 섞기 기능을 둘 수 있으나 1차 버전에서는 하지 않는다.

### 3.6 `round_half_up` 정의

`round_half_up(x) = floor(x + 0.5)`. Python 기본 `round()`는 0.5를 짝수로 반올림하므로 쓰지 않는다. (예: N=20, 0.1 → 2, N=15, 0.1 → 2)

## 5. 통계 집계 (`services/stats.py`)

이력 전체를 한 번 훑어 단어별 `WordStat`을 만든다.

```
for 기록 in 이력 where 활동 == "시험":
    stat[영단어키].attempts += 1
    if 정답여부 == "X": stat[영단어키].wrong += 1
    stat[영단어키].last_quiz_date = max(기존, 기록.일시.date())
    if 기록이 해당 단어의 가장 최근 시험 행: stat.last_correct = (정답여부 == "O")
```

- 영단어 키는 소문자 기준 (데이터 설계서 2.4).
- 시험 행이 없는 단어는 `stat` 항목이 없다. 이 경우 `WordStat`은 `None`이다.

## 6. 가중치 계산 (REQ-007)

### 6.1 규칙

`today`는 기준 날짜다. `stat`이 `None`이면 "시험 이력 없음"이다.

```
w = 1.0

if stat is None:
    w += 3.0                              # 시험 이력 없음
else:
    rate = stat.wrong / stat.attempts
    if rate >= 0.5:      w += 3.0         # 오답률 50% 이상
    elif rate >= 0.2:    w += 1.0         # 오답률 20% 이상 50% 미만
    days = (today - stat.last_quiz_date).days
    if days >= 30:       w += 2.0         # 30일 이상 경과
    elif days >= 7:      w += 1.0         # 7일 이상 30일 미만 경과
    if stat.last_correct: w -= 0.5        # 마지막 결과 정답

w = max(w, 0.5)                           # 최소 가중치
```

- `attempts > 0`인 단어만 `rate`를 계산한다.
- 한 단어가 여러 조건에 동시에 해당하면 모두 더한다 (예: 오답률 50% 이상이고 30일 경과 → +5).

### 6.2 예시

| 단어 상태 | 계산 | 가중치 |
|----------|------|-------|
| 한 번도 안 봄 | 1 + 3 | 4.0 |
| 오답률 60%, 3일 전 마지막 시험 (오답) | 1 + 3 | 4.0 |
| 오답률 0%, 40일 전 마지막 시험 (정답) | 1 + 2 − 0.5 | 2.5 |
| 오답률 25%, 2일 전 마지막 시험 (정답) | 1 + 1 − 0.5 | 1.5 |

## 7. 시험 출제 (REQ-004, REQ-007~009)

### 7.1 시험 시작 입력

| 항목 | 기본값 | 검사 |
|------|-------|------|
| 문제 수 `M` | `default_question_count` | 1 이상, 단어 수 이하. 넘으면 단어 수로 줄이고 안내 |
| 출제 방향 | 한→영 | 한→영 / 영→한 / 혼합 중 하나 |
| 문제 유형 | 단답형 | 1개 이상 선택. 0개면 시작하지 않음 |

### 7.2 문제 대상 단어 추첨

1. 풀 = 전체 단어 (D4: 1차 버전은 전체 고정).
2. 각 단어의 가중치 `w`를 6장으로 계산한다.
3. **비복원 추첨**: 아래를 `M`번 반복한다.
   - 남은 풀에서 가중치 `w`에 비례하여 한 단어를 뽑는다 (`rng.choices`).
   - 뽑은 단어는 풀에서 뺀다.
4. 결과 `M`개가 문제 대상이다. 같은 세션에서 같은 단어는 두 번 나오지 않는다 (명세서 REQ-004).

### 7.3 문제별 방향과 유형

| 항목 | 규칙 |
|------|------|
| 방향 | 선택이 "혼합"이면 `rng.choice(["한→영", "영→한"])`, 아니면 선택 값 그대로 |
| 유형 | 선택된 유형 목록에서 `rng.choice`. 한 가지만 선택하면 그 유형만 |

### 7.4 4지선다 보기 생성

대상 단어 `T`에 대해:

1. 후보 = 전체 단어 중 `T`가 아니고, `overlaps(T, 후보) == False`인 단어 (뜻 겹침 규칙, ADR-005).
2. 같은 일차 후보를 먼저 쓴다: `day_of(후보) == day_of(T)`인 후보에서 무작위로 최대 3개.
3. 3개가 안 되면 나머지 후보 전체에서 무작위로 채운다.
4. 보기 4개 = `T`의 정답 + 오답 3개 → 무작위로 섞는다.
5. 보기 표시 내용:
   - 방향 한→영: 보기는 영단어
   - 방향 영→한: 보기는 뜻 문자열 (예: `해/연도`)

후보가 3개보다 적으면(단어장이 아주 작을 때만) 4지선다를 만들지 않고, 그 문제의 유형을 단답형으로 바꾼다.

### 7.5 OX 문제 생성

1. `rng.random() < 0.5`이면 **O 문제**: 정답 쌍 `(T의 영단어, T의 뜻)`을 그대로 보여준다.
2. 아니면 **X 문제**:
   - 후보 `D`를 뽑는다. 조건은 4지선다와 같다 (`overlaps(T, D) == False`, 같은 일차 우선).
   - 방향 한→영이면 질문은 `(T의 뜻, D의 영단어)`로 만든다.
   - 방향 영→한이면 질문은 `(T의 영단어, D의 뜻)`로 만든다.
3. 정답은 O 문제면 "O", X 문제면 "X"이다.

후보가 없으면 O 문제로 바꾼다.

### 7.6 단답형 문제

- 한→영: 질문은 `T`의 뜻. 정답 목록은 `{w.english | overlaps(T, w)}`이다 (동의어 허용, REQ-009).
- 영→한: 질문은 `T`의 영단어. 정답 목록은 `T`의 뜻 토큰이다.

## 8. 채점 (`services/grader.py`)

### 8.1 답 정규화

- 단답형 입력: 앞뒤 공백 제거 후 소문자로 바꾼다. 한글은 소문자 변환 영향이 없다.
- 4지선다·OX: 선택한 보기 번호 또는 O/X 값을 그대로 쓴다.

### 8.2 판정

| 문제 유형 | 정답 판정 |
|----------|----------|
| 단답형, 한→영 | 정규화된 입력이 정답 영단어 목록(소문자)에 있으면 정답 |
| 단답형, 영→한 | 정규화된 입력이 정답 뜻 토큰 목록에 있으면 정답 |
| 4지선다 | 선택한 보기가 `T`의 보기이면 정답 |
| OX | 선택 값이 문제의 정답 ("O" 또는 "X")과 같으면 정답 |

### 8.3 결과 표시

- 정답: "정답입니다."
- 오답: "오답입니다. 정답: …"
  - 한→영 단답처럼 정답이 여러 개면 모두 나열한다. 예: `정답: store, shop`
  - 영→한 정답은 뜻 전체 문자열을 보여준다.

### 8.4 기록

답안을 제출하면 즉시 이력 1행을 `append_records`로 기록한다 (세션ID 포함). 정답여부는 `O`(정답) 또는 `X`(오답)이다.

## 9. 시험 세션 흐름

```
[시작]
  → 세션ID = "S" + 현재 시각(YYYYMMDDHHMMSS)
  → 문제 생성 (7장)
  → 문제 1 표시
[문제 i]
  → 답 입력 → 채점 (8장) → 이력 기록 → 결과 표시
  → 다음 문제
[종료]
  → 총점 = 정답 수 / M
  → 총점 표시
```

- 시험 도중 창을 닫으면 그때까지의 이력은 남는다. 남은 문제는 기록되지 않는다.
- 총점은 화면에만 표시하고 별도 파일에 저장하지 않는다. 필요한 값은 이력에서 계산한다 (보고서).

## 10. 보고서 생성 (REQ-011)

### 10.1 입력

- 기간: 최근 7일, 최근 30일, 전체 중 하나 (기본값 최근 7일, D5)
- 기준일 `today` (보고서 생성 시각)

### 10.2 기간 필터

- 기간에 해당하는 이력 행만 사용한다.
- 최근 7일 = `today - 6일` 이상 (오늘 포함 7일).

### 10.3 집계 항목

| 항목 | 계산 |
|------|------|
| 학습 일수 | 기간 내 활동이 있었던 서로 다른 날짜 수 |
| 암기 단어 수 | 활동 `암기` 행의 서로 다른 영단어 수 |
| 시험 횟수 | 기간 내 서로 다른 세션ID 수 |
| 평균 정답률 | 정답 `O` 행 수 ÷ 시험 행 수 (시험 행이 없으면 "해당 없음") |
| 자주 틀린 단어 Top 10 | 기간 내 시험 출제 3회 이상인 단어를 오답률 내림차순, 같으면 오답 수 내림차순으로 정렬해 10개 |

### 10.4 출력

- 보고서 텍스트를 만든 뒤 `data/reports/report_YYYYMMDD_HHMMSS.txt`로 저장한다 (데이터 설계서 8절).
- 이력이 없으면 파일을 만들지 않고 "이력 없음"을 표시한다 (명세서 REQ-011).
- 무시한 이력 행 수가 있으면 보고서 하단에 적는다.
