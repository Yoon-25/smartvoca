## 3. 기능 요구사항

### REQ-001 단어 데이터 로드

- **설명**: 프로그램 시작 시 기본 단어 파일 `data/voca_2000.csv`를 읽어 단어장으로 사용한다.
- **입력**: CSV 파일 (헤더 `번호,영단어,품사,뜻`)
- **처리 규칙**
  - 헤더 행이 정확히 일치하지 않으면 오류 메시지를 표시하고 로드를 중단한다.
  - 빈 칸이 있는 행은 건너뛰고, 건너뛴 행 번호를 알린다.
  - 영단어가 중복되면 첫 번째 행만 사용하고 나머지는 알린다.
- **수용 기준**
  - [ ] 기본 파일 로드 후 단어 2,000개가 목록에 표시된다.
  - [ ] 헤더가 틀린 파일을 열면 오류 메시지가 뜨고 기존 단어장은 바뀌지 않는다.
  - [ ] 빈 칸·중복 행이 있는 파일에서 건너뛴 행 정보가 표시된다.

### REQ-002 단어장 불러오기 / 저장

- **설명**: 사용자가 파일 대화상자에서 단어장을 불러오거나, 현재 단어장을 CSV로 저장한다.
- **처리 규칙**
  - 저장은 임시 파일에 먼저 쓴 뒤 원본을 교체한다. 쓰기 중 오류가 나면 원본을 건드리지 않는다.
  - 저장 형식은 REQ-001과 같다 (번호는 저장 시 1부터 다시 매긴다).
  - 파일 인코딩은 UTF-8로 고정한다.
- **수용 기준**
  - [ ] 저장한 파일을 다시 불러오면 단어 수와 내용이 원래와 같다.
  - [ ] 저장 중 실패해도 기존 파일 내용이 남아 있다.

### REQ-003 단어 암기

- **설명**: 오늘 일차의 단어를 카드로 보여주며 외우게 한다.
- **화면 동작**
  - 카드 앞면에 영단어, 뒷면에 뜻을 표시한다.
  - "뜻 보기" 버튼으로 뒷면을 열고, "다음" / "이전" 버튼으로 이동한다.
  - 카드를 끝까지 넘기면 "암기 완료" 상태가 된다.
- **이력**: 카드를 "뜻 보기" 하거나 완료할 때 암기 이력을 남긴다 (REQ-010).
- **수용 기준**
  - [ ] 1일차 카드는 단어장의 1~N번째 단어만 포함한다.
  - [ ] 마지막 카드 뒤에서 "다음"을 누르면 완료 메시지가 뜬다.

### REQ-004 단어 시험

- **설명**: 사용자가 정한 조건으로 문제를 출제하고 채점한다.
- **시험 조건**
  - 문제 수 (1 ~ 단어 풀 크기, 기본값 10)
  - 출제 방향 (REQ-008)
  - 문제 유형 (REQ-009, 복수 선택 가능)
- **채점**
  - 답변 직후 정답 여부와 정답을 표시한다.
  - 시험 종료 시 총점(정답 수 / 문제 수)을 표시한다.
- **수용 기준**
  - [ ] 문제 수 10을 정하면 정확히 10문제가 출제된다.
  - [ ] 같은 세션 안에서 같은 단어가 두 번 나오지 않는다.
  - [ ] 채점 결과가 시험 이력에 저장된다 (REQ-010).

### REQ-005 일차별 진도 생성

- **설명**: 설정한 하루 단어 수 N에 따라 단어장을 일차로 나눈다.
- **계산 규칙**
  - 일차 수 = 올림(단어 수 ÷ N). 예: 2,000 ÷ 20 = 100일차.
  - i일차의 신규 단어 = 단어장의 (i−1)×N+1 번째부터 i×N 번째까지.
  - 마지막 일차는 남은 단어만 포함한다.
- **설정 범위**: N은 10 ~ 100 정수 (기본값 20).
- **진도 저장**: 현재 일차와 마지막 학습일을 `data/progress.json`에 저장한다.
- **수용 기준**
  - [ ] N=20이면 전체 일차는 100개다.
  - [ ] 2,000번째 단어는 100일차에 포함된다.
  - [ ] N을 바꾸면 일차 구성이 다시 계산된다.

### REQ-006 복습 단어 추가

- **설명**: 일차 학습 세트에 복습 단어를 섞는다.
- **구성 (N개 기준, 기본값)**

| 구분 | 기본 비율 | 선택 규칙 |
|------|----------|----------|
| 전날 복습 | 20% | 전날 신규 단어 중 무작위 |
| 오답 복습 | 10% | 오답률 높은 순 상위 단어 중 무작위 |
| 신규 단어 | 나머지 | 일차 범위의 단어 |

- **규칙**
  - 같은 단어가 신규와 복습에 동시에 들어가면 한 번만 포함하고, 빈 자리는 다음 신규 단어로 채운다.
  - 전날 학습 기록이 없으면 전날 복습 비율만큼 신규 단어로 대체한다.
  - 비율은 설정에서 0% ~ 50% 사이로 바꿀 수 있다.
- **수용 기준**
  - [ ] N=20 기준 전날 복습 4개, 오답 복습 2개가 포함된다 (기록이 충분할 때).
  - [ ] 한 학습 세트 안에 중복 단어가 없다.

### REQ-007 무작위 출제 및 가중치

- **설명**: 시험 문제를 무작위로 뽑되, 이력이 필요한 단어가 더 자주 나오게 한다.
- **가중치 기본 규칙** (설계 단계에서 조정 가능)

| 조건 | 가중치 가산 |
|------|------------|
| 시험 이력 없음 | +3 |
| 오답률 50% 이상 | +3 |
| 오답률 20% 이상 50% 미만 | +1 |
| 마지막 출제 후 30일 이상 | +2 |
| 마지막 출제 후 7일 이상 30일 미만 | +1 |
| 마지막 결과가 정답 | −0.5 |

- 기본 가중치는 1이며, 최소 가중치는 0.5로 한다.
- 가중치 합에 비례하여 무작위 추출한다 (가중치 추첨).
- **수용 기준**
  - [ ] 시험 이력이 없는 단어가 이력 있는 단어보다 자주 출제된다 (1,000회 모의 추첨으로 확인).
  - [ ] 가중치 계산 결과가 설정 화면 또는 로그에서 확인 가능하다.

### REQ-008 출제 방향 선택

- **설명**: 문제가 한글 제시인지, 영어 제시인지 정한다.

| 방향 | 제시 | 정답 |
|------|------|------|
| 한→영 | 뜻 | 영단어 |
| 영→한 | 영단어 | 뜻 |
| 혼합 | 문제마다 무작위로 위 두 방향 중 하나 | 방향에 따름 |

- **수용 기준**
  - [ ] 혼합 선택 시 한→영과 영→한 문제가 모두 나온다.

### REQ-009 출제 유형 선택

- **설명**: 문제 형태를 정한다. 여러 유형을 함께 고르면 문제마다 무작위로 유형을 정한다.

| 유형 | 방식 | 채점 규칙 |
|------|------|----------|
| 단답형 | 텍스트 입력 | 대소문자·앞뒤 공백 무시. 뜻이 여러 개인 경우 "/"로 나뉜 뜻 중 하나만 맞아도 정답 |
| 4지선다형 | 보기 4개 중 선택 | 정답 1개 + 오답 3개 (아래 "뜻 겹침" 규칙 적용) |
| OX형 | 제시된 뜻이 맞는지 O/X 선택 | 정답 뜻(O) 또는 뜻이 겹치지 않는 다른 단어의 뜻(X)을 50:50으로 제시 |

- **뜻 겹침 규칙 (A안, ADR-005)**
  - 두 단어의 뜻 중 "/"로 나눈 토큰이 하나라도 같으면 "뜻이 겹친다"고 본다. 예: `shop`(가게)과 `store`(가게)는 겹친다.
  - 4지선다 오답 보기는 정답과 뜻이 겹치지 않는 단어에서만 뽑는다. 같은 일차 단어를 우선하고, 부족하면 전체 단어에서 뽑는다.
  - OX형 X 문제의 뜻도 정답 단어와 뜻이 겹치지 않는 단어에서 가져온다.
  - 단답형 한→영 문제에서는 정답 단어와 뜻이 겹치는 모든 영단어를 정답으로 허용한다 (동의어 허용). 예: 뜻 `가게`에 `store` 또는 `shop`을 모두 정답 처리.
  - 단답형 영→한 문제는 뜻 토큰 중 하나만 맞아도 정답 처리한다 (REQ 기존 규칙과 동일).

- **수용 기준**
  - [ ] 4지선다 보기는 항상 4개이고, 정답과 뜻이 겹치는 보기가 없다.
  - [ ] 단답형에서 `Apple`, ` apple ` 입력이 모두 정답으로 처리된다.
  - [ ] 한→영 단답에서 뜻이 겹치는 동의어 단어(예: `shop`, `store`)를 입력해도 정답으로 처리된다.
  - [ ] OX형 X 문제의 뜻은 정답 단어의 뜻과 겹치지 않는다.

### REQ-010 이력 저장

- **설명**: 암기와 시험 결과를 CSV에 누적 저장한다.
- **파일**: `data/study_history.csv`
- **열 구성**

| 열 | 설명 | 예시 |
|----|------|------|
| 일시 | 활동 시각 (YYYY-MM-DD HH:MM:SS) | 2026-10-21 14:30:00 |
| 활동 | 암기 / 시험 | 시험 |
| 세션ID | 시험 한 번을 묶는 값 (암기는 빈칸) | S20261021143000 |
| 영단어 | 대상 단어 | apple |
| 출제방향 | 한→영 / 영→한 / 암기 | 한→영 |
| 유형 | 단답형 / 4지선다 / OX / 암기 | 4지선다 |
| 정답여부 | O / X / 빈칸(암기) | O |

- **규칙**
  - 파일이 없으면 헤더와 함께 새로 만든다.
  - 기록은 추가(append) 방식으로 쓴다. 기존 행은 수정하지 않는다.
- **수용 기준**
  - [ ] 시험 10문제를 풀면 이력에 10행이 추가된다.
  - [ ] 프로그램을 껐다 켜도 이력이 유지된다.

### REQ-011 보고서 생성

- **설명**: 사용자가 요청하면 이력을 바탕으로 텍스트 보고서를 만든다.
- **입력**: 기간 선택 (최근 7일 / 최근 30일 / 전체)
- **보고서 내용**

| 항목 | 계산 방식 |
|------|----------|
| 학습 일수 | 활동이 있었던 날짜 수 |
| 암기 단어 수 | 활동 "암기" 행의 고유 단어 수 |
| 시험 횟수 | 고유 세션ID 수 |
| 평균 정답률 | 정답 O 수 ÷ 시험 행 수 |
| 자주 틀린 단어 Top 10 | 오답률 높은 순 (출제 3회 이상인 단어만) |

- **출력**: `data/reports/report_YYYYMMDD_HHMMSS.txt`
- **수용 기준**
  - [ ] 기간을 바꾸면 보고서 수치가 달라진다.
  - [ ] 이력이 없으면 "이력 없음" 메시지를 표시하고 파일을 만들지 않는다.
